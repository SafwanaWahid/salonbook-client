# SalonBook Client

SalonBook is a salon appointment booking platform where customers discover services, request appointments, and pay after confirmation. Administrators manage salon services, customers, bookings, and transactions.

## Technology stack

Next.js, TypeScript, React, Better Auth, REST API, and Tailwind CSS.

## Local setup

1. Copy `.env.example` to `.env.local` and set the API, auth, and public app URLs.
2. Run `npm install`.
3. Run `npm run dev` and open `http://localhost:3000`.

## Environment variables

- `NEXT_PUBLIC_API_URL`
- `NEXT_PUBLIC_APP_URL`
- `NEXT_PUBLIC_AUTH_URL`

## Features

- Service discovery, search, category filtering, and price sorting
- Better Auth email/password and Google sign in
- Customer booking flow and role-based dashboards
- Stripe Checkout and payment status pages
- Responsive salon-themed interface
